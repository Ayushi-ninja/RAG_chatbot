# RAG Development Skill

This skill covers retrieval-augmented generation (RAG) development tasks for the repository.

You should:
- Understand the current architecture and data flow before changing RAG logic.
- Preserve existing data ingestion, embedding creation, and retrieval behavior unless the task explicitly requires a change.
- Keep vector store and search semantics stable.
- Prefer adding configuration or adapters over rewriting core retrieval logic.
- Document any model, API, or data source changes clearly.
