# Next.js Development Skill

This skill focuses on Next.js or frontend React app logic.

You should:
- Respect the existing frontend structure and avoid unnecessary rewrites.
- Keep page and component behavior stable unless the task demands changes.
- Preserve site routing, API integration, and build conventions.
- Prefer incremental updates and clear separation between UI and data logic.
- Ensure any new UI code works with the current project setup.
